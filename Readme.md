# 6주차 JavaScript 이벤트 & 동적 UI 및 탭 구현 기록

## 확인한 문제
정적 UI 및 사용자 인터랙션 부재:
  * 주요 기능 섹션이 단순 나열식으로 배치되어 있어 콘텐츠 집중도가 떨어지고 탐색 편의성 저하
  * 사용자 입력 및 선택에 즉각적으로 반응하는 시각적 피드백 부재
  * 다크 모드 등 사용자 환경에 맞춘 스타일 전환 기능 부재

## 수정한 내용
3개 탭 UI 구현 (주요 기능 전환):
  * 주요 기능 섹션(#features)에 3개 탭 버튼('유통기한 임박', '맞춤 레시피', '3일 전 알림') 및 대응하는 패널 구성
  * querySelectorAll 및 `forEach`를 활용하여 탭 클릭 시 선택된 탭만 활성화(`is-active`, `aria-selected: true`)하고 나머지 패널은 숨김(`hidden`) 처리
다양한 이벤트(click, input, change) 핸들러 구현:
  * click 이벤트: 테마 변경 버튼 클릭 시 `classList.toggle('dark')`를 통해 배경/스타일 전환 및 버튼 문구 동시 변경
  * input 이벤트: 식재료 이름 입력창에 글자 입력 시 실시간으로 글자 수(최대 10자)를 계산하여 화면 문구 갱신
  * change 이벤트: 알림 수신 동의 체크박스 상태 변경 시 안내 문구(`textContent`), 성공 스타일(`is-ready`), 버튼 비활성화 해제(`disabled: false`)가 동시에 적용되도록 복합 상태 변경 로직 작성
반응형 레이아웃 및 웹 접근성 점검:
  * 탭 및 패널 구조에 WAI-ARIA 속성(`role="tab"`, `role="tabpanel"`, `aria-controls` 등)을 적용하여 접근성 향상
  * `@media (max-width: 768px)` 환경에서 탭 버튼 및 이벤트 설정 카드가 세로 1열로 자동 전환되도록 반응형 CSS 유지

## 달라진 점
동적 인터랙션 및 UX 향상:
  * 3개 탭 전환을 통해 필요한 기능 정보를 깔끔하게 분리하여 전달력 강화
  * 입력 및 체크 상태에 따라 문구·스타일·버튼 상태가 즉각적으로 연동되어 사용자 행동에 대한 명확한 피드백 제공
다양한 해상도(1100px·768px·390px) 호환성 유지:
  * 1100px(데스크톱): 탭 버튼과 이벤트 카드가 넓은 가로 그리드로 시원하게 배치
  * 768px(태블릿): 탭 버튼 및 실습 카드가 세로 1열로 정렬되어 터치 영역 최적화
  * 390px(모바일): 가로 스크롤이나 내용 잘림 없이 모든 입력 폼, 버튼, 탭 기능이 안정적으로 작동
