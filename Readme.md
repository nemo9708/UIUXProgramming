## 11주차 웹 접근성 개선

* 개선한 요소:
  * 색 대비 및 비색상 상태 표시: 보조 텍스트 명도 대비를 4.5:1 이상으로 상향(`#4b4e5c` 등)하고, 현재 메뉴(`aria-current="page"`)와 선택된 필터(`aria-pressed="true"`)에 밑줄·체크 기호(`✓`)를, 오류 문구에 경고 기호(`⚠`)를 추가해 색상 없이도 상태를 구분할 수 있도록 개선했습니다.
  * 명확한 라벨·상태 전달: 글자 수 안내(`#foodNameCount`)의 반복 낭독을 막기 위해 `aria-live`를 제거하고 `aria-describedby`로 연결했습니다. 메뉴 이동 시 `document.title`을 갱신하고, 폼 검증 오류(`aria-invalid="true"`) 및 제출 중 상태(`aria-busy="true"`)를 동적으로 반영했습니다.
  * 키보드 접근성 및 초점 관리: 최상단에 본문 바로가기(Skip Link)를 추가하고, 모든 상호작용 요소에 고대비 `:focus-visible` 초점 테두리를 적용했습니다. 모바일 메뉴 `Esc` 닫기 및 초점 복귀, 현황판 카드 상태 변경 후 필터 버튼으로 초점 복귀를 구현했습니다.

* 정상 경로 (행동 → 반응 → 다음 행동):
  * `Tab`으로 본문 바로가기 실행 → `#mainContent`로 이동 → 상단 메뉴·주요 기능 탭·현황판 필터를 키보드로 탐색
  * 간편 등록 1~3단계 정상 입력 → 요약 확인 후 최종 등록 → 4단계 완료 안내 표시 및 실시간 현황판에 새 식재료 카드 즉시 반영
  * 맞춤 알림 폼에서 이메일/문자 선택 및 정상 입력 후 제출 → `알림 정보 등록 중...`(버튼 비활성화, `aria-busy="true"`) → 완료 문구(`✓`) 표시

* 다른 경로 (오류 / 결과 없음 / 상태 변경 테스트 결과):
  * 빈 입력 오류: 간편 등록 1단계 또는 맞춤 알림 폼에서 필수 항목을 비운 채 진행 시 `⚠` 오류 문구 표시, `aria-invalid="true"` 적용 및 오류 입력창으로 초점 자동 이동 확인
  * 검색 결과 없음(Empty State): 존재하지 않는 식재료 검색 시 빈 상태 안내 표시 → `필터 초기화` 버튼으로 전체 목록 및 초점 복귀 확인
  * 카드 상태 변경: '보관 중' 필터에서 식재료 `소비 완료 처리` 실행 시 목록 갱신 후 현재 선택된 필터 버튼으로 초점이 안전하게 복귀함 확인
  * 조건부 입력 제외: 맞춤 알림에서 '알림 안 함' 선택 시 연락처 입력창 숨김(`hidden`) 및 비활성화(`disabled`)되어 `Tab` 이동에서 제외됨 확인

* 키보드·모바일 확인:
  * 데스크톱에서 마우스 없이 `Tab` / `Shift+Tab` / `Enter` / `←·→`(탭)만으로 전 기능 조작 및 초점 표시 확인
  * 모바일 너비(`768px`, `390px`)에서 가로 스크롤 없음, 모바일 메뉴 열기 → `Esc` 키 닫기 → `메뉴 열기` 버튼으로 초점 복귀 확인


  ## 12주차 UI 컴포넌트와 반복 가능한 인터페이스 구조

* 구현한 UI 컴포넌트 및 반복 구조:
  1. 아코디언(Accordion) — 자취생 식재료 보관 꿀팁 FAQ (`#tipsSection`)
     * 사용자의 행동: 질문 버튼을 클릭하거나 `Enter`·`Space` 키를 눌러 보관법을 펼치고 접음
     * 공통 규칙: `.accordion-item`, `.accordion-trigger`, `.accordion-panel` 공통 클래스와 `initAccordions()` 공통 이벤트 함수로 3개 항목의 여백·크기·초점 규칙 통일
     * 상태별 반응: 닫힘(`aria-expanded="false"`, `+` 기호, `hidden`) → 열림(`aria-expanded="true"`, `−` 기호, 밑줄·강조색 적용 및 답변 표시)
  2. 모달(Modal Dialog) — 식재료 맞춤 레시피 추천 (`#recipeModal`)
     * 사용자의 행동: 현황판 카드의 `추천 레시피` 버튼을 눌러 해당 식재료의 활용 레시피를 확인하고, `닫기 ✕`·`확인했습니다`·배경 클릭·`Esc` 키로 창을 닫음
     * 공통 규칙: `role="dialog"`, `aria-modal="true"`와 `.modal-backdrop`, `.modal-dialog` 구조로 어떤 식재료를 선택하든 동일한 레이아웃과 버튼 규칙 재사용
     * 상태별 반응: 선택한 카드 데이터(`name`, `category`, `storage`)에 맞춰 모달 제목·부제·레시피 문구 동적 변경, 열릴 때 닫기 버튼으로 초점 이동 및 닫힐 때 원래 카드 버튼으로 초점 복귀
  3. 데이터 기반 카드 생성 함수 분리 (`createFoodCard(item)`)
     * 공통 규칙: 목록 렌더링(`renderFoodList()`)에서 카드 한 장을 생성하는 `createFoodCard(item)` 함수를 분리해 기존 데이터와 신규 등록 데이터 모두 동일한 카드 구조(`.food-item-card`, `.card-actions`)로 생성
     * 상태별 반응: D-Day(`여유`/`주의`/`임박`/`만료`)와 소비 여부(`storing`/`consumed`)에 따라 배지 색·기호·버튼 문구(`소비 완료` ↔ `되돌리기`)가 자동으로 전환

* 브라우저 확인 결과:
  * 넓은 화면(PC) 및 좁은 화면(768px 이하, 390px): PC 화면에서 아코디언·모달·카드 하단 버튼 가로 배치 정상 출력, 모바일 화면에서 카드 1열 정렬 및 모달·아코디언 가로 잘림 없음 확인
  * 키보드 및 다크 테마: `Tab`·`Enter`·`Esc`만으로 아코디언과 모달 조작 및 초점 복귀 정상 동작, 다크 테마 전환 시에도 텍스트와 버튼 대비 유지 확인
