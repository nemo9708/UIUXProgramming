# 신선한 냉장고 - 7주차 사용자 흐름(Task Flow) 프로젝트

## 1. 서비스 정보 및 목적
- 서비스명: 신선한 냉장고
- 주요 사용자: 식재료 유통기한을 놓치기 쉬운 1인가구 및 자취생
- 서비스 목적: 냉장고 속 식재료 유통기한을 한눈에 파악하고 알림을 등록하여 음식을 버리는 일을 방지합니다.

## 2. 완료할 핵심 행동 및 조건
- 핵심 행동: 식재료 정보 입력 ➔ 보관 방식 및 유통기한 설정 ➔ 최종 확인 ➔ 등록 완료
- 완료 조건: 식재료명, 카테고리, 보관장소, 유통기한의 필수값이 모두 올바르게 입력되어야 최종 완료 단계에 도달함.

## 3. 사용자 흐름 (Task Flow) 시나리오
1. 1단계 (기본 정보): 식재료 이름과 카테고리를 선택합니다. 필수값 미입력 시 에러 문구가 출력되고 진행이 차단됩니다.
2. 2단계 (보관 및 기한): 보관 장소와 유통기한 날짜를 지정합니다.
3. 3단계 (최종 확인): 이전 단계에서 입력한 데이터가 요약 상자에 자동 반영됩니다. 이전 버튼 클릭 시 입력한 값이 그대로 유지된 채 수정할 수 있습니다.
4. 4단계 (등록 완료): 완료 메시지가 표시되며, '다른 식재료 추가 등록하기' 클릭 시 모든 입력값과 상태가 초기화되어 1단계로 되돌아갑니다.

## 4. 인터랙션 구조
- `행동`: 다음 버튼 클릭 ➔ `이벤트`: click ➔ `조건`: 필수값 validation ➔ `화면 반응`: 에러 메시지 노출 또는 다음 패널 보이기 ➔ `다음 상태`: 해당 Step 활성화

## 5. 반응형 테스트 결과
