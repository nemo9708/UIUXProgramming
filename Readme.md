# 신선한 냉장고 - 9주차 조건부 입력 폼 및 제출 처리 보고서

## 1. 추가 및 수정한 기능 설명
본인이 기획한 '신선한 냉장고' 서비스에 맞춰 '맞춤 식재료 보관 알림 신청 폼'을 신규 추가했습니다.  
사용자가 알림 수신 방식(이메일, 문자, 수신 안 함)을 선택함에 따라 추가 입력창의 표시/비활성화(`disabled`) 상태가 동적으로 바뀌며, 입력 중 실시간 유효성 검사 및 제출 중 중복 방지 피드백을 제공합니다.

---

## 2. 평가 항목별 기능 및 확인 순서 (테스트 가이드)

### [항목 1] 서비스에 맞는 폼 구성
* 확인 순서: 페이지 하단의 '맞춤 식재료 보관 알림 신청' 폼으로 이동합니다.
* 구현 내용:
  * 식재료명, 알림 방식 선택, 연락처 입력 필드로 구성
  * 폼 컨트롤러별 명확한 라벨(`label`), 플레이스홀더(`placeholder`), 도움말(`small`) 제공
  * 필수 항목 시각적 표시(`<span class="required">*</span>`) 적용
