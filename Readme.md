# 4주차 반응형 CSS 수정 기록

## 확인한 문제
390px 모바일 화면 레이아웃 깨짐:
  * 내비게이션 메뉴와 이메일 입력 폼이 가로로 나열되어 텍스트 영역이 좁아지고 버튼이 화면 밖으로 밀리는 문제 발생
  * 모바일 환경에서 터치 및 가독성 저하

## 수정한 내용
메타 태그 점검:
  * index.html에 viewport 메타 태그가 정상 적용되어 있는지 확인
CSS Grid 레이아웃 도입:
  * 기능 카드 목록(#features ul)에 grid-template-columns 속성을 적용하여 화면 크기에 맞춰 유연하게 반응하도록 개선
모바일 미디어 쿼리 적용 (@media (max-width: 768px)):
  * 내비게이션(nav): flex-direction: column으로 변경하여 세로 배치 및 터치 영역 확보
  * 기능 카드(#features ul): 모바일 화면에서 1열(1fr) 고정 배치
  * 이메일 입력 폼(form): 입력창과 버튼을 세로 1열로 배치하고, 버튼 최소 높이(min-height: 48px)를 설정하여 모바일 조작 편의성 향상

## 달라진 점
반응형 최적화 완료:
  * 1100px(데스크톱), 768px(태블릿), 390px(모바일) 등 다양한 해상도에서 가로 스크롤이나 텍스트 잘림 현상 제거
  * 좁은 화면에서도 정보를 한눈에 파악하고 폼을 원활하게 입력할 수 있도록 모바일 UX 개선
